# 固定虚构评测集

`cases.jsonl` 的六组案例均为虚构文本，不包含真实业务文件。每行列出招标/投标文本块、预期一致性类别以及按源块和类别标注的要求匹配状态。

进入 `/evals` 可运行规则评测或包含模型调用的完整评测。每次运行保存数据集 SHA256、提示词版本/哈希、模型参数、Git 提交和工作区是否有未提交修改，以及耗时、可获得的 token 用量和逐案例结果。

`baseline-2026-09-04.json` 是实际运行结果，包括失败案例。匹配 Macro-F1 为 53.3%，尚未达到 75% 的原定目标。要求提取允许原子化拆分，而本集合按整条源块标注；当拆分后的状态不一致时保守计为 uncertain，不挑选最佳匹配。后续应扩展带独立原子标注的文档对，单独评估页码和检索范围。

重跑可能受模型行为和供应商变化影响。此集合是回归检查起点，不是业务准确率认证。
